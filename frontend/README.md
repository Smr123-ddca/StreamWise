# StreamWise - Frontend

This directory will contain the user interface for the **StreamWise** intelligent video streaming system.

## Planned Technology Stack

- **Framework**: React
- **Build Tool**: Vite
- **Language**: JavaScript (ESNext)
- **Styling**: Tailwind CSS
- **Video Player**: Shaka Player / HLS.js (future integration)

## Planned Responsibilities

- Video playback with adaptive / intelligent segment switching.
- Real-time display of streaming metrics (buffer health, active bitrate, segment resolution).
- User preference configuration (e.g., data saver mode, visual quality priority, latency tolerance).
- Network conditions reporting and telemetry hooks.

> **Status**: Reserved for future module implementation.
