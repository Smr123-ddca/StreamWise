# Glossary

- **Decision intelligence**: content-aware selection of a rendition for each upcoming segment.
- **Marginal utility**: quality gain from one single-step rendition upgrade.
- **Rolling window**: the ordered upcoming segment set considered in one decision call.
- **Safety margin**: multiplier applied to estimated throughput before budgeting or simulation.
- **Switching penalty**: cost assigned to changing rendition level between adjacent segments.
- **VMAF**: Video Multi-Method Assessment Fusion, a perceptual quality score commonly represented on a 0–100 scale.
